# خطة التطوير والتنفيذ - تبسيط المنظومة، دمج المكرر، وتحليل المبيعات المحوري (Pivot)

## 1. التنظيف ودمج المكرر (تم الإنجاز بنجاح ✓)
- **صفحة الحوافز (`IncentivesPage.tsx`)**:
  - دمج `IncentivesModal` + `IncentiveBreakdownModal` في صفحة موحدة تحتوي على:
    - تاب إدارة قواعد وبنود الحوافز مع نموذج إضافة قواعد وتنزيل نموذج الإكسيل مباشرة.
    - تاب حاسبة استحقاق الموظفين مع لوحة بيان الصرف التفصيلي المباشرة في الصفحة دون نوافذ منبثقة معطلة.
    - تاب التوقعات الشهرية للشرائح والمكافآت.
- **صفحة التقارير والتصدير (`ReportsPage.tsx`)**:
  - دمج `MonthlyReportModal` + `ExecutivePresentationCard` + `ExportAndDownloadCenterModal` + `DownloadManager` في 3 تابات مدمجة:
    1. توليد العرض التنفيذي والتقرير الشهري الشامل مع جاهزية الطباعة وتصدير PDF.
    2. مركز تصدير الملفات (Excel / CSV / النماذج الرسمية لشركة راية).
    3. سجل التنزيلات والمزامنة (Download History).
- **صفحة المخزون الذكي (`InventoryPage.tsx`)**:
  - دمج `SmartInventoryOptimizerModal` + `AbcAnalysisSection` في تابات مدمجة:
    1. رادار المخزون وتوصيات المناقلات الفورية لفرع كونكورد بلازا (مخزن 0032).
    2. تحليل ABC وتصنيف باريتو للمخزون ومبيعات الأقسام.
    3. سجل أرصدة المخازن الفعلية من أوراكل (0032 كونكورد مقابل 4016 المستودع المركزي).

## 2. الواجهة الرئيسية المبسطة - 5 عناصر أساسية + ودجت الفئات الأكثر مبيعاً (تم الإنجاز بنجاح ✓)
- تطبيق لغة التصميم النظيفة: لون أساسي أزرق + ألوان الحالة (أخضر/أصفر/أحمر) فقط، خلفيات بيضاء نظيفة، مسافات واسعة، ورقم رئيسي واحد بارز في كل كارت:
  1. **كارت الريفينيو**: إجمالي المبيعات المحققة الصافية برقم بارز ضخم، مقابل التارجت، نسبة الإنجاز % مع شريط تقدم نظيف، وبلوكات الإحصائيات (المتبقي للتارجت، المطلوب يومياً، الأيام المتبقية في الشهر).
  2. **تقدم الفئات**: أربعة أقسام (موبايلات، إكسسوارات، أخرى، التقسيط) مع شريط نسبة الإنجاز، وإظهار "لم يُدخل بعد" عند عدم توفر بيانات.
  3. **أهم 3 تنبيهات**: كارت مخصص بأهم 3 تنبيهات تشغيلية بلون الحالة مع زر "عرض الكل" لفتح مركز التنبيهات.
  4. **أفضل 3 موظفين**: لوحة شرف بالثلاثة الأوائل (🥇، 🥈، 🥉) مع صافي المبيعات ونسبة التحقيق.
  5. **منحنى الأداء ومسار التارجت**: رسم بياني تراكمي يقارن الأداء الفعلي بخط التارجت اليومي.
- **ودجت الفئات الأكثر مبيعاً (أعلى 5 فئات بالكمية)**:
  - يعرض أعلى 5 فئات بالقطع المباعة الصافية، وقيمتها بالجنيه، وتفريعة الماركات الأعلى داخلها كأزرار سريعة.
  - النقر على أي فئة أو ماركة ينقل المستخدم مباشرة إلى تاب تحليل المبيعات (Pivot) مع تطبيق الفلتر فوراً.
- **عرض المزيد (Show More)**: زر قابل للطي أسفل العناصر الـ 5 يحتوي على التوقع التفصيلي لنهاية الشهر وملخص البيانات التشغيلية.
- **زر "+" واحد**: زر عائم يفتح قائمة العمليات الأربعة (رفع إكسيل، إضافة سجل، تقرير، تصدير).
- **الشريط العلوي الموحد**: اختيار الفترة/الفرع، زر البحث Ctrl+K، جرس التنبيهات، وقائمة "⋯" (اللغة، احتساب الضريبة، العملة، تثبيت الهاتف).

## 3. تحليل المبيعات (جدول محوري Pivot Table) (تم الإنجاز بنجاح ✓)
- **متاح في صفحة المبيعات (`/sales`)** تحت تاب "تحليل المبيعات (Pivot)".
- **الأبعاد المدعومة**: القسم، الماركة (موحدة)، الموديل، المستشار، التاريخ اليومي، الفترة، والفرع.
- **محرك توحيد الماركات (`Brand Normalization`)**: يزيل فروق الهمزات والأحرف الكبيرة والصغيرة والتهجئة العربية/الإنجليزية تلقائياً.
- **الفلاتر السريعة الجاهزة (Quick Presets)**:
  - ماركة × قسم
  - موظف × قسم
  - يوم × قسم
  - مستشار × ماركة
- **حفظ طرق العرض المخصصة (Saved Views)**: حفظ أي تركيبة أبعاد وفلاتر مخصصة في التخزين المحلي والتبديل بينها بنقرة واحدة.
- **مقاييس القيمة**: صافي الكميات (بعد خصم المرتجعات)، القيمة شاملة الضريبة، القيمة قبل الضريبة، عدد الفواتير، ومتوسط سعر القطعة.
- **تصدير إكسيل ومعاينة تفاصيل الخلايا (Drilldown)**.
